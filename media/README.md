# 媒体工作台

图片、语音、音乐、3D 工作台共用持久队列。所有成员都可查看、下载和使用共享任务、成果与图片档案；“显示所有用户”可切换为仅看本人内容。创建者可修改、取消和删除自己的内容，管理员可管理他人内容。复用参数或重试生成会创建当前账号自己的新任务，源内容及归属保持不变。图片档案支持逐图标签、批量导入、新增、删除和参考图选择。

每个任务保存提交账号和当时的模型选择，后台恢复仍使用该账号的原配置。个人 API 配置只对本人可见，共享任务中的个人连接标识和名称会隐藏。借用别人任务重试时使用当前账号选择的模型，成果归当前账号。

不同 API 配置可并行制作，默认最多 4 个任务；环境变量 `COMMUNITY_MEDIA_WORKERS` 可设为 1～16。同一 API 配置按顺序执行，避免多个任务争用只接受单任务的服务。取消只影响对应任务；已经提交的远端任务会继续跟踪完成后丢弃成果，不会停止其他用户的远端模型。服务重启后凭已保存的远端任务 ID 恢复查询，未知提交结果不会盲目重发。

删除已结束任务会删除该任务目录，包括上传参考图或训练数据、工作流请求和全部生成成果。平台无法直接删除供应商的远端缓存，请按所用 API 的保留策略管理。

## 音乐训练

音乐 REST API 在能力检测中声明并通过 `music_train` 验证后，制作方式中显示“训练 LoRA 微调”。普通成员和管理员均可通过自己可使用的个人或全局 API 提交，训练任务和生成权重归提交账号。需要上传不超过 256 MiB 的 ZIP，最多 500 个 WAV、MP3 或 FLAC，解压后总计不超过 2 GiB；平台检查路径、格式与大小，不在本机解压或运行训练。

保留训练轮数、LoRA 秩、学习率和样本时长参数。训练说明直接使用原文，不启用 LLM 翻译。数据以 ZIP 字节发送给所选 API，返回的 safetensors 权重或包含权重的 ZIP 进入资产库，可下载或随任务完整删除。普通生成保留音乐描述、风格标签、歌词、纯音乐开关、时长、步数和种子。具体服务请求格式见 [API 契约](../portal/API_CONTRACT.md)。
