提示词方式

可选择档案中的任意图片，所选原图显示在右侧。图片标签仅用于查找，不会转换成朝向要求。

默认使用参考图片；勾选后才补充角色文字档案。主参考图决定观看角度。

最多 12000 字符。动作提示词原文保留，不经过 LLM 改写。工作台自动附加纯灰背景、固定镜头、完整主体等透明动画约束。参考图片与可选参考视频仍作为输入条件，最终输出透明帧与精灵图。

补充参考图片（可选）

主参考图始终为图片 1，补充图片会按所选顺序一起提交；最多添加 8 张。

已选 0 / 8 张补充图片

移除仅取消本次选择，已上传源文件仍保留。切换角色会清空补充图片选择。

直接描述要制作的动作与效果，最多 3000 字。识图 LLM 结合主参考图的姿态、肢体结构与朝向，把你的意图展开成动作时序、重心转移和关节运动等具体指令；请先配置通过识图检测的视觉模型；灰底、固定镜头和完整主体由工作台固定附加。使用动作参考视频时可以不填写文字。

生成流程：所选视频 API → 透明背景处理 → 导出透明帧与精灵图。必须绑定支持透明背景编辑的图片 API，逐帧去除背景。原视频保留，输出需人工核对。

辅助模式保持主参考图的观看角度、原地动作与固定镜头。每次提交生成一个任务；正式生产前请确认角色档案。

辅助模式生成前检查识图 LLM、视频 API 与抠图 API 配置。

直接模式使用所选视频 API，不调用识图 LLM 辅助。
